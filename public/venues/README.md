# Venue photos

Place venue images here. They are referenced from `lib/data/default-porto-venues.ts`
via paths like `/venues/<slug>-<n>.jpg`.

Currently expected files:

- `quinta-loureiro-1.jpg` — Quinta Loureiro Eventos (banquet hall with chandeliers)
- `quinta-alferes-1.jpg`  — Quinta do Alferes de Crasto (rooftop deck at sunset)

Add more by extending the `photos` array on the venue entry and dropping the
file in this folder. JPEG / WEBP, ≥ 1200 px wide is recommended.
